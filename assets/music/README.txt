背景音乐说明
========================================

现在已经放好了：miss.m4a（王力宏《错过》，8 MB，全长 3 分 59 秒）
播放起点设在第 13 秒（"北风毫不留情"那句）。
想微调的话，打开上一层的 assets/music.js：

  startAt: 13      想早一点就改小，晚一点就改大；写 "0:15" 这种也行
  loop: false      想循环播就改成 true
  volume: 0.5      音量
  title: "…"       鼠标悬停在右下角音符按钮上显示的名字

如果哪天换了歌：
  1. 把新文件放进这个文件夹
  2. 把 music.js 里的 file 改成新文件名

几点提醒
----------------------------------------
· 这首歌是有版权的商业作品。放在公开仓库里理论上可能被
  权利人投诉下架（GitHub 收到投诉会关掉 Pages）。风险不大但存在，
  你自己权衡；不放音乐的话其他功能完全不受影响。
· 8 MB 在手机上首次打开会多等几秒（会边下边播，不用等它下完）。
  想让体积小一点，可以用任何音频工具压到 128kbps（约 3~4 MB），
  或者只截取前一两分钟。
· 万一在手机上不响：把这个文件改名为 miss.mp4，同时把 music.js 里的
  file 也改成 assets/music/miss.mp4（个别环境对 m4a 的识别不一样）。
· 没放音乐文件时右下角不会出现音符按钮，页面也不会报错。
