背景音乐说明
========================================

文件：miss.m4a（王力宏《错过》，8 MB，全长 3 分 59 秒）
起点：第 13 秒（"北风毫不留情"那句）

打开网页就会尝试自动播放，音量由小到大（约 2.5 秒渐入到 50%）。

浏览器有自动播放限制，所以实际表现是：
· 允许自动播放时 → 一打开就响
· 被拦下时 → 你第一次点/按页面任何地方（比如点密码框）就立刻开始，
  不用专门去点右下角的音符按钮

想调整，打开上一层的 assets/music.js：

  startAt: 13      起点秒数，写 13 或 "0:13"
  volume: 0.5      最终音量
  fadeIn: true     是否由小到大
  fadeMs: 2500     渐入时长（毫秒）
  loop: false      播完是否重头再来
  title: "…"       鼠标悬停显示的名字
  file: "…"        换歌时改这里

几点提醒
----------------------------------------
· 手机开着「静音 / 震动」开关时，网页声音也会被静音，先检查一下。
· 这首歌有版权，放在公开仓库里理论上可能被投诉下架（GitHub 收到
  投诉会关掉 Pages）。不放音乐的话其他功能完全不受影响。
· 8 MB 在手机上首次打开会多等几秒（边下边播，不用等它下完）。
· 万一手机上不响：把文件改名成 miss.mp4，同时把 music.js 里的
  file 一起改。
