# 我们的纪念日 💞（带密码锁）

纯静态的私密纪念日网站：**内容加密后放在公开仓库里，没有密码的人只能看到一把锁。**
免费托管在 GitHub Pages，链接长期有效，你电脑关机也能打开。

## 它长什么样

打开网址 → 一把锁 + 一个输入框 → 输对密码 → 内容在**你自己的浏览器里**解密显示：

- 首屏大数字：在一起多少天，秒级实时跳动
- 下一个纪念日倒计时，到期那天变金色
- 里程碑：下一个整数百天 / 520 / 999 / 1314
- 时间轴：初次相遇、确定关系、爬泰山……按时间自动排好
- 纪念日卡片墙：每个显示下次日期和剩余天数
- 页脚「每日一句」：按日期轮流显示，一天换一条
- 背景音乐：解锁后从指定秒数开始播（可选，见下文）
- 手机端适配

## 文件结构

```
anniversary/
├── index.html          页面骨架（解锁页 + 内容区）
├── secret.js           ★ 加密后的内容，只有密文，可以公开
├── assets/
│   ├── crypto.js       加解密（PBKDF2 派生密钥 + AES-256-GCM）
│   ├── gate.js         解锁逻辑（密码、钥匙链接、记住本机）
│   ├── main.js         页面渲染与计算
│   ├── music.js        背景音乐开关（起点秒数在这里改）
│   ├── music/          音乐文件放这里（miss.m4a）
│   └── style.css       样式（换配色改最上面的 :root）
├── .nojekyll
└── README.md
```

> 📁 **这个文件夹里的东西全部都可以公开上传**——里面没有任何明文（`secret.js` 只有密文）。
> ⚠️ 生成内容用的《加密工具.html》在**上一层**（和 `anniversary` 并排放着），它含明文，**永远不要上传**。

## 更新内容：三步

1. 双击打开**上一层文件夹**里的 `加密工具.html`（纯本地运行，密码不会发到任何地方）
2. 改里面的内容 → 填入和现在**一样的密码** → 点「生成加密文件」
   - 工具会顺手用同一个密码解一遍做校验，并告诉你解析出的名字和天数，防止改坏
   - 内容会自动存在这台电脑的浏览器里，下次打开还在
   - **如果模板更新过**（比如新加了时间轴）：打开时会提示"这是你上次的本机草稿"，点「载入模板内容」就能拿到最新模板，再按需要微调
3. 下载 `secret.js`，覆盖原来的，上传到 GitHub（等一分钟网站就更新）

## 发链接给他/她

- **手动版**：发网址，让对方输密码。勾上「在这台设备上记住」，下次在同一台设备就不用再输
- **省事版**：在工具里点「复制钥匙链接」，把那条链接直接发过去，点开就进，不用输密码
  - 打开后地址栏里的钥匙会被自动抹掉（避免截图/复制地址时把密码带出去）
  - 换密码重新生成 `secret.js` 后，旧钥匙链接立刻失效

## 背景音乐

已经放好了：`assets/music/miss.m4a`（王力宏《错过》，8 MB，全长 3 分 59 秒），**从第 13 秒开始播**（"北风毫不留情"那句）。打开网页就会尝试自动播放，音量由小到大淡入。

想微调，打开 `assets/music.js`：

- `startAt`：起点秒数，写 `13` 或者 `"0:13"` 都行
- `volume`：最终音量，0 ~ 1
- `fadeIn` / `fadeMs`：音量是否由小到大、渐入多少毫秒（默认 2.5 秒）
- `loop`：改成 `true` 就是循环播放
- `file`：换歌时改这里（新文件放进 `assets/music/`）

**五个必须知道的点**

- **打开网页就会尝试自动播放**，音量由小到大淡入。浏览器有自动播放限制：允许时一打开就响；被拦下时你**第一次点/按页面任何地方**（通常就是点密码框）就立刻开始，不用专门去点右下角按钮
- 手机开着**静音 / 震动开关**时，网页声音会被一起静音 —— 先检查一下这个
- 这首歌有版权，放在公开仓库里理论上可能被投诉下架（GitHub 收到投诉会关掉 Pages）；不放音乐其他功能完全不受影响
- 8 MB 在手机上首次打开会多等几秒（边下边播，不用等它下完）。想更小，用音频工具压到 128kbps 大约 3~4 MB
- 万一手机上不响：把文件改名成 `miss.mp4`，同时把 `music.js` 里的 `file` 一起改

## 想换密码怎么办

1. 打开 `加密工具.html`（内容不用动，原样保留）
2. 把「密码」和「再输一遍」改成**新密码**
3. 生成 → 下载新的 `secret.js` → 覆盖上传

换了之后会发生三件事：

- 工具给出的**钥匙链接变成新的**，旧链接立刻失效 → 把新链接重发给对方
- 双方设备（之前勾过"在此设备上记住"的）下次打开要**重新输一次密码**
- **旧密码生成的 `secret.js` 备份从此打不开**，所以新密码和新的明文都要留一份

## 安全说明（如实讲）

**做到了什么**

- 内容是 AES-256-GCM 加密的，密钥由密码经 PBKDF2（30 万次迭代）派生
- 仓库和服务器上只有密文，明文配置**不存在于网站上**
- 密码错一个字符都解不开（这条是实测过的），密文被改坏也解不开
- 页面标题、正文在解锁前都是中性的，不泄露名字

**没做到什么**

- 这不是账号体系，没有"给谁单独授权/单独踢掉谁"的能力，本质是**一把共享的钥匙**
- 密文是公开的，别人可以把 `secret.js` 下载走，在自己电脑上离线慢慢猜密码
  → 所以密码要够强：**12 位以上，或者一句只有你俩知道的话**；别用生日、`520`、`woaini` 这类
- 「在这台设备上记住」会把解密密钥存进那台设备的浏览器本地存储（不是明文密码）
  → 公用手机会有风险；共用电脑建议不要勾。换过 `secret.js` 后会自动作废
- **忘记密码 = 内容彻底解不回来**，没有找回通道。工具里的明文草稿请自己另存一份（例如存到本地文件或私密笔记里）
- 仓库里永远不要放明文内容，也不要把明文发给任何人（包括我）

## 发布到 GitHub Pages（约 5 分钟）

1. 登录 [github.com](https://github.com)，**+ → New repository**，名字填 `anniversary`，选 **Public**，Create
2. 点 **uploading an existing file**，把 `anniversary` 文件夹里的东西**全部**拖进去（同名文件会自动覆盖），Commit
   - `assets` 文件夹要一起拖（样式、脚本、音乐、图标都在里面）
   - `.nojekyll` 是隐藏文件，选不到也没关系
3. **Settings → Pages**：Source 选 `Deploy from a branch`，Branch 选 `main`、目录 `/ (root)`，Save
4. 等 1～2 分钟刷新该页，拿到网址：`https://你的用户名.github.io/anniversary/`
5. 首次打开输一次密码（勾「记住」），或者直接在工具里复制钥匙链接发给对方

以后更新内容：在工具里改 → 重新生成 `secret.js` → 在仓库里点开 `secret.js` → 铅笔图标 → 粘贴新内容 → Commit。

## 已知限制

- GitHub Pages 免费档只能用公开仓库 —— 本方案用加密规避了内容泄露，但**网址本身是公开可访问的**（打开只会看到锁）
- 局域网 http 地址（如 `http://192.168.x.x:8123`）下浏览器禁用加密接口，网页会提示"这个地址打不开"。**手机测试请用部署后的 https 网址**；本机 `127.0.0.1` 或直接双击文件没问题
- Chrome/Edge/Safari/Firefox 现代版本都支持；很老的浏览器打不开锁
