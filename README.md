# 我们的纪念日 💞（带暗号锁）

纯静态的私密纪念日网站：**内容加密后放在公开仓库里，没有暗号的人只能看到一把锁。**
免费托管在 GitHub Pages，链接长期有效，你电脑关机也能打开。

## 它长什么样

打开网址 → 一把锁 + 一个输入框 → 输对暗号 → 内容在**你自己的浏览器里**解密显示：

- 首屏大数字：在一起多少天，秒级实时跳动
- 下一个纪念日倒计时，到期那天变金色
- 里程碑：下一个整数百天 / 520 / 999 / 1314
- 时间轴：第一次见面、第一次旅行……
- 纪念日卡片墙：每个显示下次日期和剩余天数
- 手机端适配

## 文件结构

```
anniversary/
├── index.html          页面骨架（解锁页 + 内容区）
├── secret.js           ★ 加密后的内容，只有密文，可以公开
├── assets/
│   ├── crypto.js       加解密（PBKDF2 派生密钥 + AES-256-GCM）
│   ├── gate.js         解锁逻辑（暗号、钥匙链接、记住本机）
│   ├── main.js         页面渲染与计算
│   └── style.css       样式（换配色改最上面的 :root）
├── 加密工具.html         ★ 在本机生成 secret.js 的工具，双击就能用
├── .nojekyll
└── README.md
```

> ⚠️ **《加密工具.html》绝对不要上传到 GitHub**：它里面的模板就是你们的明文内容（名字、生日、日期），传上去等于公开。它只在本机用来生成 `secret.js`。

## 更新内容：三步

1. 双击打开 `加密工具.html`（纯本地运行，暗号不会发到任何地方）
2. 改里面的内容 → 设定暗号 → 点「生成加密文件」
   - 工具会顺手用同一个暗号解一遍做校验，并告诉你解析出的名字和天数，防止改坏
   - 内容会自动存在这台电脑的浏览器里，下次打开还在
3. 下载 `secret.js`，覆盖原来的，上传到 GitHub（等一分钟网站就更新）

## 发链接给他/她

- **手动版**：发网址，让对方输暗号。勾上「在这台设备上记住」，下次在同一台设备就不用再输
- **省事版**：在工具里点「复制钥匙链接」，把那条链接直接发过去，点开就进，不用输暗号
  - 打开后地址栏里的钥匙会被自动抹掉（避免截图/复制地址时把暗号带出去）
  - 换暗号重新生成 `secret.js` 后，旧钥匙链接立刻失效

## 安全说明（如实讲）

**做到了什么**

- 内容是 AES-256-GCM 加密的，密钥由暗号经 PBKDF2（30 万次迭代）派生
- 仓库和服务器上只有密文，明文配置**不存在于网站上**
- 暗号错一个字符都解不开（这条是实测过的），密文被改坏也解不开
- 页面标题、正文在解锁前都是中性的，不泄露名字

**没做到什么**

- 这不是账号体系，没有"给谁单独授权/单独踢掉谁"的能力，本质是**一把共享的钥匙**
- 密文是公开的，别人可以把 `secret.js` 下载走，在自己电脑上离线慢慢猜暗号
  → 所以暗号要够强：**12 位以上，或者一句只有你俩知道的话**；别用生日、`520`、`woaini` 这类
- 「在这台设备上记住」会把解密密钥存进那台设备的浏览器本地存储（不是明文暗号）
  → 公用手机会有风险；共用电脑建议不要勾。换过 `secret.js` 后会自动作废
- **忘记暗号 = 内容彻底解不回来**，没有找回通道。工具里的明文草稿请自己另存一份（例如存到本地文件或私密笔记里）
- 仓库里永远不要放明文内容，也不要把明文发给任何人（包括我）

## 发布到 GitHub Pages（约 5 分钟）

1. 登录 [github.com](https://github.com)，**+ → New repository**，名字填 `anniversary`，选 **Public**，Create
2. 点 **uploading an existing file**，把 `index.html`、`secret.js`、`README.md` 和 `assets` 文件夹拖进去，Commit
   - `assets` 文件夹要一起拖（样式和脚本都在里面）
   - `.nojekyll` 传不传都行；`加密工具.html` **不要传**（里面有明文内容）
3. **Settings → Pages**：Source 选 `Deploy from a branch`，Branch 选 `main`、目录 `/ (root)`，Save
4. 等 1～2 分钟刷新该页，拿到网址：`https://你的用户名.github.io/anniversary/`
5. 首次打开输一次暗号（勾「记住」），或者直接在工具里复制钥匙链接发给对方

以后更新内容：在工具里改 → 重新生成 `secret.js` → 在仓库里点开 `secret.js` → 铅笔图标 → 粘贴新内容 → Commit。

## 已知限制

- GitHub Pages 免费档只能用公开仓库 —— 本方案用加密规避了内容泄露，但**网址本身是公开可访问的**（打开只会看到锁）
- 局域网 http 地址（如 `http://192.168.x.x:8123`）下浏览器禁用加密接口，网页会提示"这个地址打不开"。**手机测试请用部署后的 https 网址**；本机 `127.0.0.1` 或直接双击文件没问题
- Chrome/Edge/Safari/Firefox 现代版本都支持；很老的浏览器打不开锁
